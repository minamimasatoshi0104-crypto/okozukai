# おこづかい帳

中学生向けのおこづかい管理アプリ（PWA）。データは Google スプレッドシートに保存し、Apps Script を API として使う。

- `docs/` … アプリの画面（GitHub Pages で公開）
- `gas/` … Apps Script のコード（スプレッドシートに貼り付ける）

記録・レシート・コメントなどのデータはリポジトリに入らない。API キーなどの秘密情報は Apps Script のスクリプトプロパティに置き、コードには書かない。

## 進め方

| 段階 | 内容 | 状態 |
|---|---|---|
| 1 | 記録の基本（ホーム・入力・ワンタップ・履歴・修正・保護者のマーク・Google ログイン） | 実装済み |
| 2 | 月末の締め・報告カード・承認・振り返り | 実装済み |
| 3 | レシートの AI 読み取り・AI コーチのレビュー（Claude Haiku 5.5） | 未着手 |
| 4 | Google カレンダーでのリマインド | 未着手 |

## セットアップ（初回のみ）

### 1. スプレッドシートと Apps Script

1. 保護者の Google アカウントで、新しいスプレッドシートを作る（名前は「おこづかい帳データ」など）
2. メニューの「拡張機能」→「Apps Script」を開く
3. `gas/Code.gs` の中身を `コード.gs` に貼り付ける
4. 左の「プロジェクトの設定」→「appsscript.json をエディタで表示する」をオンにし、`gas/appsscript.json` の中身を貼り付ける
5. 関数 `setup` を選んで「実行」する（権限の確認が出たら許可する）。シートが4枚できる（締め用の `closes` シートは、初めて締めたときに自動でできる）

### 2. Google ログイン用のクライアント ID

1. https://console.cloud.google.com/ で新しいプロジェクトを作る
2. 「API とサービス」→「OAuth 同意画面」を設定する（外部・テストユーザーに家族のアカウントを追加）
3. 「認証情報」→「認証情報を作成」→「OAuth クライアント ID」→ 種類「ウェブ アプリケーション」
4. 「承認済みの JavaScript 生成元」に `https://<GitHubユーザー名>.github.io` を追加する
5. できたクライアント ID を控える

### 3. スクリプトプロパティ

Apps Script の「プロジェクトの設定」→「スクリプト プロパティ」に追加する。

| プロパティ | 値 |
|---|---|
| `GOOGLE_CLIENT_ID` | 手順2のクライアント ID |
| `PARENT_EMAILS` | 保護者の Google アカウント（複数はカンマ区切り） |
| `CHILD_EMAILS` | 子どもの Google アカウント |

### 4. API として公開

1. Apps Script の「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
2. 実行ユーザー「自分」、アクセスできるユーザー「全員」でデプロイする
3. 表示されたウェブアプリの URL を控える

「全員」にしても、データの読み書きは登録した家族の Google アカウントからしかできない（API 側でログインを確認している）。

### 5. 画面の設定と公開

1. `docs/config.js` の `apiUrl` と `clientId` を、手順4の URL と手順2のクライアント ID に書き換える
2. VS Code の「ソース管理」→「Publish to GitHub」→ public repository で公開する
3. GitHub のリポジトリの「Settings」→「Pages」で、Branch を `main`、フォルダを `/docs` にして保存する
4. 数分後に `https://<GitHubユーザー名>.github.io/okozukai/` で開ける

### 6. スマホに入れる

- Android（Chrome）：URL を開く →「︙」→「ホーム画面に追加」
- iPhone（Safari）：URL を開く → 共有ボタン →「ホーム画面に追加」

Family Link で管理しているアカウントは、「Google でログイン」に保護者の許可が必要な場合がある。

## コードを更新したとき

- 画面（`docs/`）：コミットして GitHub に push すれば数分で反映される
- Apps Script（`gas/`）：エディタに貼り付け直し、「デプロイを管理」→ アプリが使うデプロイ（v1）を選ぶ → 鉛筆アイコン →「バージョン：新バージョン」で更新する（URL は変わらない）
  - 「新しいデプロイ」は押さない。別の URL ができ、アプリからは使われない
  - 更新のたびに `Code.gs` の `VERSION` を上げる。ウェブアプリの URL をブラウザで開くと `version` が表示されるので、上がっていれば反映済み
  - 「デプロイを管理」に出る「バージョン N」は Apps Script の保存版の番号で、`VERSION` とは別物。プルダウンで「新バージョン」を選ばないと、古い保存版のまま公開される
